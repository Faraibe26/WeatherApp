

# 🌦️ Weather App

A simple GUI-based weather application built with Python and Tkinter that allows users to get real-time weather information for any city using the OpenWeatherMap API.

## 🚀 Features

- Search weather for any city worldwide 🌍
- Real-time weather updates: temperature and description ☁️
- Easy-to-use graphical interface built with Tkinter 🎨
- Lightweight and beginner-friendly code base 🧠

## 📦 Requirements

- Python 3.x
- [requests](https://pypi.org/project/requests/)
- [OpenWeatherMap API key](https://openweathermap.org/appid)

## 🔧 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/weather-app.git
   cd weather-app
   ```

2. Install dependencies:
   ```bash
   pip install requests
   ```

3. Replace the placeholder API key with your own in `Weather.py`:
   ```python
   api_key = 'your_api_key_here'
   ```

4. Run the app:
   ```bash
   python Weather.py
   ```

## 📄 Usage

- Enter a city name (e.g., **London**, **New York**, **Tokyo**).
- Click the **"Get Weather"** button.
- View the weather information displayed below.

## 💡 Example Output

```
Weather in Paris: Clear sky, Temperature: 22°C
```
